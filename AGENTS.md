# Coding preferences

- Make the smallest complete change; preserve unrelated work.
- Reuse existing code and native platform features before adding dependencies.
- Keep appropriate error handling, accessibility, and verification.
- Record completed features and fixes with local Git commits containing the related code, tests, and documentation. Do not push without a request.
- Do not commit build products, machine logs, credentials, or runtime data.
- Badge monitoring reads only Dock metadata; do not read chat content or add network access.
